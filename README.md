# go-ai-logging

A `go test` runner for AI coding agents: it keeps the complete test output on disk and prints a short, bounded summary that points into it. Standard library only.

**Status:** pre-release, no API yet; v0.1.0 is planned.

```sh
go get github.com/entur/go-ai-logging # Go 1.26 or later
```
